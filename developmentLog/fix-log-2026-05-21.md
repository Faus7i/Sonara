## 已修复问题

### P0 — 严重（运行时 NRE）

#### ✅ 问题 1：`ImportTrackCommandHandler` — `trackObj.Album` null NRE

- **文件**：`src/Modules/Catalog/Handlers/ImportTrackCommandHandler.cs`
- **修复**：在调用 `GetOrCreateAlbumAsync` 前加 null 检查，Spotify 本地文件无专辑信息时抛出 `NotFoundException`（明确原因），不再 NRE
- **代码**：
  ```csharp
  if (trackObj.Album is null)
      throw new NotFoundException($"曲目 {request.SpotifyTrackId} 无专辑信息（可能为本地文件），无法导入");
  ```

#### ✅ 问题 2：`ImportTrackCommandHandler` — `trackObj.Artists` null NRE

- **文件**：同上
- **修复**：`trackObj.Artists` 传入 `GetOrCreateArtistsAsync` 前加 `?? new()` 回退
- **代码**：
  ```csharp
  var artists = await GetOrCreateArtistsAsync(trackObj.Artists ?? new(), ct);
  ```

### P2 — 中等（逻辑缺陷 / 并发安全）

#### ✅ 问题 6：4 个 Import Handler 缺少 `DbUpdateException` 并发处理

以下 4 个 Handler 的 `SaveChangesAsync` 统一加上 try-catch（SQL 2601/2627 → 返回已有数据）：

| 文件 | 修复方式 |
|------|---------|
| `Catalog/Handlers/ImportTrackCommandHandler.cs` | catch 后 `AsNoTracking` 重查 Track 含导航属性 |
| `Catalog/Handlers/ImportArtistCommandHandler.cs` | catch 后 `AsNoTracking` 重查 Artist |
| `AudioFeatures/Handlers/ImportAudioFeaturesCommandHandler.cs` | catch 后 `AsNoTracking` 重查批量已有特征 |
| `AudioFeatures/Handlers/GetAudioFeaturesQueryHandler.cs` | catch 后 `AsNoTracking` 重查单曲特征 |

- 使用 `AsNoTracking()` 避免与未提交的追踪实体冲突
- 添加 `using Microsoft.Data.SqlClient;`（识别 `SqlException`）

### 低优 — 代码质量
